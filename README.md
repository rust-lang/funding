# Funding
This repository serves for discussions and design documents about funding Rust maintainers, such as via the [Rust Foundation Maintainer Fund](https://rustfoundation.org/media/announcing-the-rust-foundation-maintainers-fund/) (RFMF). It serves as the home of the Rust [Funding team][funding-team].

In the past, it was also used to coordinate the work of the [Rust Foundation Maintainer Fund Design subcommittee](https://github.com/rust-lang/leadership-council/pull/248).

[funding-team]: https://rust-lang.org/governance/teams/launching-pad/#team-funding

## Maintainer in Residence

One of the main initiatives led by the Funding team is the [Maintainer in Residence](./md/mir.md) program.
